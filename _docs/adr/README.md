# ADR

アーキテクチャ上の判断を、1 ファイル 1 決定で残す。

調査メモ（pnpm の差分など）は ADR にしない。採用・却下・保留が決まったとき、または決めたいときに書く。

## 置き場

| 状態 | 場所 |
| --- | --- |
| 下書き | `_drafts/` |
| 決定（Accepted など） | `_docs/adr/` |

番号は 4 桁。次の番号は、既存ファイルの最大 + 1。

## 書き方

1. `0000-template.md` をコピーする
2. ファイル名を `0001-short-title.md` にする
3. 必須は「背景 / 選択肢 / 決定 / 捨てた理由」だけ
4. 決まっていない項目は空欄か `未定` のままでよい
